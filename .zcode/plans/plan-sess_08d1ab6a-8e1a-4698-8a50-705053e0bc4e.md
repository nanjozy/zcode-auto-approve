# v0.4：hook 运行时改用 ZCode.exe（ELECTRON_RUN_AS_NODE），去除 fnm node 依赖

两轮访谈结论：ZCode.exe 优先 + fnm node 兜底（安装时二选一）；接受"ZCode 更新可能静默失效"（fail-safe 转人工）+ installer 冒烟验证 + 文档披露；**若实测 hook 注册不支持 env 字段则整体否决**；探测顺序 `ZAA_ELECTRON` env > 默认安装路径 > 兜底。

## 0. 事实门（批准后第一步，任一失败即停止并汇报，方案否决）
1. `ELECTRON_RUN_AS_NODE=1 ZCode.exe -e "console.log(process.versions.node)"` —— fuse 是否关闭、内嵌 node 版本（需 ≥18，内置 fetch）；
2. 启动延迟对比 ZCode.exe vs fnm node（各 3 次计时，预算 30s 充裕即可）；
3. deny-path 真实冒烟：`echo '{...rm -rf /...}' | ELECTRON_RUN_AS_NODE=1 ZCode.exe src/approve.mjs` —— 期望空输出 exit 0、审计落盘（不调模型、不花配额）。
4. 检索 app.asar 确认 ZCode 自身是否内部使用 ELECTRON_RUN_AS_NODE（旁证，非门禁）。

## 1. ADR-0009（先于代码）：hook 运行时来源
- 决策：注册 `command: ZCode.exe` + `env: {ELECTRON_RUN_AS_NODE: "1"}`，安装时验证通过才采用，否则回退 fnm node 绝对路径；理由：ZCode.exe 路径经 electron-updater 原位更新不变（比 fnm 版本切换更稳）、彻底去用户 node 依赖。
- 备选与否决理由：cmd.exe wrapper（引回 shell，违背 ADR-0002 选 `type:process` 初衷）、ELECTRON_RUN_AS_NODE 独占（无退路）。
- 风险披露：非承诺通道（fuse 可关/实现可改）；env 字段若被静默忽略，症状=每次审批弹异常窗口（Electron 单实例锁使其短暂无害），重跑 install 回退。
- 状态：Accepted（用户访谈确认，2026-09-16）；ADR-0002 加注记（注册运行时部分演进见 ADR-0009，单文件+type:process+绝对路径原则不变）。

## 2. `scripts/install.mjs` 改造
- `resolveElectron()`：`ZAA_ELECTRON` > `%LOCALAPPDATA%\Programs\ZCode\ZCode.exe` 存在性探测；
- `verifyElectronRuntime()`（依赖注入，可测）：run-as-node 版本探针 + deny-path 冒烟（均带 ELECTRON_RUN_AS_NODE）；
- 通过 → 写注册 `{command: <ZCode.exe>, env: {ELECTRON_RUN_AS_NODE: "1"}, args: [approve.mjs], timeoutMs: 30000, ...}`，输出"已采用 ZCode.exe 路线 + 失效回退提示"；不通过 → 现行 fnm node 逻辑 + 输出回退原因。幂等/备份逻辑复用。
